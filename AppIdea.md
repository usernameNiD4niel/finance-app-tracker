# FINANCE APP TRACKER

## Features
- Create daily expense
- Add/Update monthly salary (consider every 15th day salary)
- Create bills (monthly, weekly or daily)
- Preview the current balance for the month
- View the statistics of current month, day or week vs other month, week or day
- Allow the user to create a target expense for the month
- Show the progress of savings
- Dashboard of the entire expenses and other expenditures

## Technical
- No login but create a pin or much better if uses face pass or current phone password/face
- Must be an offline app
- Can be use by both IOS user and Android user
- Database is local only
- Must be modern UI & UX app, make sure to invest more to this also.
- For the tech stack, use React Native or Flutter for cross platform app.
- For the database, use any SQL DB, just make sure that it should be store on the user phone.
