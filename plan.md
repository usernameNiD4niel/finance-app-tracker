│ Context                                                                                                                                                                                                                          │
│                                                                                                                                                                                                                                  │
│ The finance tracker app currently uses a flat Material Design 3 style with card borders, minimal shadows, and high-contrast backgrounds (white in light mode, near-black in dark mode). The goal is to convert the entire UI to  │
│ a neomorphism (neumorphism) design language — soft, extruded/embossed elements that appear to push out from or sink into the background surface. This must work in both light and dark modes, be consistent across all screens,  │
│ and be easy on the eyes (no harsh contrasts).                                                                                                                                                                                    │
│                                                                                                                                                                                                                                  │
│ Reference: assets/img.png — dark finance app with subtle card depth, clean typography, gradient hero card.                                                                                                                       │
│                                                                                                                                                                                                                                  │
│ ---                                                                                                                                                                                                                              │
│ Approach: boxShadow Style Prop (No Extra Libraries)                                                                                                                                                                              │
│                                                                                                                                                                                                                                  │
│ React Native 0.81.5 (new architecture enabled by default in Expo SDK 54) supports the native boxShadow style prop on both iOS and Android. This supports:                                                                        │
│ - Multiple shadows (needed for neumorphism's dual light + dark shadow)                                                                                                                                                           │
│ - Inset shadows (for pressed/concave states)                                                                                                                                                                                     │
│ - Spread distance                                                                                                                                                                                                                │
│                                                                                                                                                                                                                                  │
│ All existing elevation, shadowColor, shadowOffset, shadowOpacity, shadowRadius will be replaced with boxShadow arrays.                                                                                                           │
│                                                                                                                                                                                                                                  │
